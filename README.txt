How to run the project:
Create the database and tables using the commands in ddl.sql
The program will insert all the data in data.sql, and it will
take a while since the tables contain over 1000 rows
Use the command in project directory:
mvn spring-boot:run
Navigate to http://localhost:8080/login.html in your browser

Technology:  
-Front-end: HTML, CSS, JavaScript
-Back-end: Java and Spring Boot using a maven project structure 
-Database: MySQL, JDBC connection 
-Build Tools: Maven, Git, Docker
