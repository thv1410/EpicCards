Overview:
EpicCards is a containerized, full-stack study platform engineered to help students master complex concepts and accelerate exam preparation. Built with Java Spring Boot, Docker, and a relational SQL database, the application provides high-concurrency backend services with robust CRUD operations for creating, organizing, and reviewing custom flashcard decks.
